# MediQueue – Tutor Booking System

MediQueue is a full-stack tutor booking platform where students can browse tutors, view tutor details, and book available sessions.

## 🌐 Live Website

https://mediqueue-dusky.vercel.app



## ✨ Features

* 🔐 Email/Password & Google Authentication
* 👨‍🏫 Browse and search available tutors
* 📅 Book tutor sessions with date validation
* 📚 Add, update and delete personal tutors
* 📝 View and cancel booked sessions
* 🌙 Dark/Light theme
* 📱 Fully responsive design

## 🛠️ Technologies

**Frontend:** Next.js, React, Tailwind CSS, HeroUI
**Backend:** Express.js, MongoDB
**Authentication:** Better Auth & JWT
**Deployment:** Vercel
